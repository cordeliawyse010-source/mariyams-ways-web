MARIYAM’S WAYS FOUNDATION — WEBSITE PREVIEW
===========================================

HOW TO OPEN
1. Unzip the folder.
2. Double-click index.html to open it in Safari, Chrome or another browser.
3. Use the navigation to visit Home, About, Our Work, Contact and Request Outreach.
4. Internet is not required for the website to load. If you have Internet, the Poppins font may be fetched from Google Fonts; otherwise the site uses a local system-font fallback.

WHAT WORKS
- All five responsive pages and navigation links.
- Mobile navigation menu.
- Contact form field validation and visible preview notice.
- Interactive five-step Request Outreach flow, with programme choice,
  multiple audience choices, input validation, review summary and completion.

IMPORTANT
This is a standalone HTML/CSS/JavaScript prototype. No backend, email service,
or database is connected. Contact messages and outreach requests are NOT SENT.
The completion screen explicitly describes a preview, not a real submission.
Do not put real personal information into this offline demonstration.

ASSETS
The logo and real outreach photographs were reconstructed/cropped from the
user’s Figma screenshots. Their resolution is limited; replace them with the
original photographs when available under assets/images while keeping the file
names or updating the referenced paths in the HTML.

EDITING
- HTML page content: index.html, about.html, our-work.html, contact.html, outreach.html
- Main styling: css/style.css
- Mobile/tablet styling: css/responsive.css
- Interactive behavior: js/main.js, js/contact.js, js/outreach.js

DEPLOYING
You can upload the folder’s files as-is to a static hosting service such as
Cloudflare Pages, GitHub Pages or Netlify. To receive contact/outreach messages,
connect a suitable backend or form submission service and add privacy/security
requirements before accepting real submissions.
